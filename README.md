🏏 Cricket Score Management

A modern and interactive Cricket Score Management Web App built using React and Vite. This application allows users to manage live cricket matches, track scores, and simulate real-time gameplay with an intuitive UI.

🚀 Live Demo

👉 https://AravindSaravananGitHub.github.io/Cricket-Score-Management/

📌 Features
🏏 Create and manage cricket matches
📊 Live score tracking (runs, wickets, overs)
👥 Player and team management
🔄 Real-time UI updates
📱 Responsive design for all devices
⚡ Fast performance using Vite
🛠️ Tech Stack
⚛️ React.js
⚡ Vite
🎨 CSS (Custom styling)
📦 gh-pages (for deployment)
